# Why this desk has no front end

A service owner needs the accountable team, evidence date, dependency and next action. The database stores those facts. The coding agent runs the CLI and presents the result. The business can read branded HTML without operating an application server.

A hosted portal offers sign-in, guided forms, mobile access, visual dependency exploration and self-service infrastructure actions. This base has none of those interfaces. It has no offline synchronisation, drag-and-drop topology editor or production execution. Its local database can work without a network after installation, but an agent or shared database can still need connectivity. Port's broader platform remains a different operating scope.

Enterprise DNA builds the screens, controlled connections and permissions a customer actually needs around the owned database. The free version remains the internal catalog desk.
